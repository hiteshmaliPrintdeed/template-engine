# Stage 3.1 — Cleanup & de-cluttering

**Milestone 3 · ~1 day · No dependencies · `[BLOCKER for 3.2]`**

---

## 1. Objective

Strip every developer-only surface, dead component, and hardcoded placeholder out of the frontend so the interface only ever shows what a paying customer should see — and delete the current chat-bubble widget outright, rather than patching around it, so [Stage 3.2](M3-3.2-guided-story-studio.md) builds the Guided Story Studio into a clean file instead of inheriting old JSX, old copy, and old emoji.

This stage is pure subtraction. It ships no new capability and carries no AI/backend risk — see [Risks & rollback](#8-risks--rollback) for why it is nonetheless a hard blocker for 3.2.

---

## 4. Tasks

### Task 1 — `ToolbarHeader.jsx`

- Delete the "Boilerplate Inspector" and "System Stats" `<button>` blocks and their `Activity`/`LayoutGrid` imports.
- Delete the inert "Order this book" button and its `ShoppingBag` import.
- Replace the emoji sync badge with `<RefreshCw size={14} />` (syncing) / `<Check size={14} />` (synced) per the icon map in the PRD's design-system section.
- Keep `Clear Session` (`RotateCcw`) and `Export 300 DPI Print PDF` (`Printer`) as-is — both already correct.

### Task 2 — `SpreadViewer.jsx`

- Delete the `"Click Page to Shuffle Layout"` button and its containing action-bar `<div>` (lines 103-126).
- Replace `Spread #{spread.spread_index} ({left.page_number} & {right.page_number})` with `Spread {spread.spread_index} • Pages {left.page_number}–{right.page_number}` in muted slate typography, rendered as a plain heading (no button semantics).
- Keep `onClick={() => handleSpreadClick(...)}` on the `.spread-pair` canvas itself, and keep its `cursor: pointer` — the affordance survives, only the redundant button goes.
- Replace the `⚠️` span with `<AlertTriangle size={12} />`.

### Task 3 — `App.jsx`

- Delete the `activeMode` state, its two conditional branches, and the now-unused `BoilerplateInspector`/`SystemStatsDashboard` imports.
- `ToolbarHeader` stops receiving `activeMode`/`setActiveMode` props — its brand-logo click handler and nav buttons that referenced them go with Task 1.
- Change `useState('Friends at ISKCON Temple')` to `useState('')`.

### Task 4 — Delete now-orphaned dev components

```bash

```
Both become fully unreferenced the moment Task 3 lands; delete the files in the same change, not later.

### Task 5 — Delete dead code

```bash

```
Confirmed zero references anywhere in `frontend/src` beyond its own definition.

### Task 6 — Delete the current widget (end of Stage 3.1, on purpose)

```bash
git rm frontend/src/components/AIChatbotWidget.jsx
```

This is the literal end-of-phase action: the current chat-bubble implementation is removed outright, not incrementally edited. Because `App.jsx:695-704` still imports and renders `<AIChatbotWidget />` at `step === 'chat'`, **this leaves the app unable to progress past photo upload until 3.2 lands** — see Risks & rollback.

## 8. Risks & rollback

| Risk | Mitigation |
|---|---|
| Deleting `AIChatbotWidget.jsx` breaks the `step === 'chat'` render until 3.2 lands | Land 3.1 and [3.2](M3-3.2-guided-story-studio.md) in the same PR/session. Do not ship 3.1 alone to any environment a user can reach. |
| Removing the shuffle button also removes discoverability of the reshuffle feature for first-time users | Acceptable per the PRD's own intent (Tenet 3) — the canvas retains `cursor: pointer` and hover depth as the affordance; this is a deliberate UX simplification, not an accidental regression. |
| Grep-based emoji sweep misses an emoji outside the covered Unicode ranges | Treat the grep gate as a floor, not a ceiling — a final manual pass in Stage 3.3's UI audit is the real gate. |

**Rollback:** every change here is either a deletion or a subtraction from existing JSX — `git revert` on this stage's commit(s) fully restores prior behavior with no data-layer involvement.
